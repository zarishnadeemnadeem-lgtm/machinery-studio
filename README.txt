MACHINERY STUDIO — QUICK START

FILES
- index.html: page content and sections
- style.css: complete responsive design
- script.js: mobile menu, catalogue filters, enquiry form and WhatsApp links

BEFORE PUBLISHING
1. Open script.js.
2. Replace:
   const WHATSAPP_NUMBER = "923001234567";
   with your own WhatsApp number in international format, digits only.
   Pakistan example: 923001234567 (no +, spaces, or dashes).
3. Update the business description, catalogue items, services and contact details in index.html.
4. Save all files.

RUN LOCALLY
- Double-click index.html to open it in a browser.
- Or open the folder in VS Code and use the Live Server extension.

FREE DEPLOYMENT WITH NETLIFY
1. Keep index.html, style.css and script.js together in the same folder.
2. Visit https://app.netlify.com/drop
3. Follow the page's upload instructions. If folder upload is not accepted, zip the three files and use a deployment method supported by your Netlify dashboard.
4. For a site you can manage long-term, sign in to a free Netlify account and claim/create the site.
5. Open the published URL and test the WhatsApp button and form.

IMPORTANT
- This is a static front-end website. It has no live inventory, payment processing, user accounts, or database.
- Equipment categories and service wording are sample content; replace them with truthful details about your business.
- Test the WhatsApp number on a phone and desktop before sharing the site.
